Student Spending Analysis and Prediction Using Machine Learning

Project Overview

This project analyses student spending patterns and predicts estimated student expenses using Machine Learning.

The project uses a Kaggle dataset containing student demographic, income and spending information.

Objectives

* Analyse student spending habits.
* Identify major expense categories.
* Understand the relationship between income and expenses.
* Predict estimated student expenditure.
* Compare different Machine Learning algorithms.

Dataset

* Source: Kaggle
* Records: 1,000 students
* Features: Student demographics, income, financial aid and spending information.

Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

Machine Learning Algorithms

1. Linear Regression
2. Decision Tree Regression
3. Random Forest Regression
4. Gradient Boosting Regression

Model Evaluation

Models are evaluated using:

* MAE
* MSE
* RMSE
* R² Score

Project Workflow

1. Dataset Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Feature Engineering
6. Train-Test Split
7. Model Training
8. Model Evaluation
9. Expense Prediction

Future Scope

Historical monthly spending data can be incorporated to develop future expense forecasting capabilities.
